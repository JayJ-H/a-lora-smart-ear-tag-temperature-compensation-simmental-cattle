# Manuscript figure sources

This directory contains the source material for Figs. 1–19.

- `source_assets/`: editable Illustrator, SVG, Origin, CAD, and related source files.
- `reproduction_sources/`: repository-relative inputs, scripts, component assets, and generated panels.
- `editable_source_manifest.csv`: editable-source inventory and checksums.
- `figure_source_manifest.csv`: figure-to-source mapping.
- `figure_reproduction_manifest.csv`: data/script/component mapping for reproduction.

`figure_reproduction_manifest.csv` records the inputs, scripts, components, and
outputs for each figure. `editable_source_manifest.csv` records the editable
source files.
