- Baseline commit: `77be2821dc67d583ec17b37dca51347a9e193189`
- Export date: 2026-08-05

The public package retains the application source, database schema, deployment
templates, and anonymous TH-SHRC runtime assets. Production databases, environment
files, credentials, logs, build outputs, and machine-local files are excluded.

The runtime assets align to the 520-row public OOF table by `RecordID`. All 30 cattle use anonymous `CowKey` values, and every record uses anonymous source code `S01` with unit weight.
