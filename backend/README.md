# Management-platform source

`source_code/` contains the complete platform source, including the Web client,
Node.js API, MySQL persistence, MQTT ingestion, TH-SHRC runtime integration,
alert handling, and gateway control.

`reference/` provides a compact schema and interface view of the paper-specific
data path from tag ingestion to storage and display.

See `source_code/README.md` for installation and startup commands.
